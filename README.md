# Makina-peryodik-bakim-takibi

Bu proje, md dosyasında tanımlanan bakım takip uygulamasının ASP.NET Core MVC sürümüdür.

## Özellikler
- Bölüm, makine, personel ve bakım fişi yönetimi
- Periyodik bakım takibi
- Dashboard görünümü
- Bootstrap tabanlı responsive arayüz
- Entity Framework Core InMemory veritabanı ile çalışır

## Çalıştırma
```bash
dotnet restore
dotnet run
```

Uygulama varsayılan olarak http://localhost:5100 adresinde çalışacaktır.
